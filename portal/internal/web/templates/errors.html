Reading these numbers

  • Scale-from-zero 503 responses ({{num .Totals.ColdStarts}} in this range) are recorded with cold_start=true when a scale-to-zero model is either waking up (model_scaled_to_zero) or refused because no GPU capacity is currently free (insufficient_capacity). They are counted separately rather than as failed requests.
  • Requests rejected at the edge before model resolution (for example missing/invalid API keys at Tyk or pre-routing 404s on unknown paths) return before model-gateway writes a ledger row and therefore do not appear here.
  • If an error persists and the summary above does not explain it, contact support@tech.alliancecan.ca with the model ID, timestamp (UTC), and HTTP status.
