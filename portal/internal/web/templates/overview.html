Reading these numbers

  • {{if .Oldest.IsZero}}No usage records are currently indexed.{{else}}Records on hand span {{longdate .Oldest}} to {{longdate .Newest}}, and this index refreshed at {{ts .RefreshedAt}}. {{if .Coverage.Partial}}{{count .Coverage.IncompleteDays "day" "days"}} in this range {{if eq .Coverage.IncompleteDays 1}}has{{else}}have{{end}} incomplete records, marked on this page.{{else}}Every day in this range has complete records.{{end}}{{end}}
    • {{template "gpu-note"}}
  • Thinking tokens are a subset of output tokens reported by reasoning-capable models (never added a second time to total tokens). The Models page shows which models reported them.
  • Comparisons with the previous period appear only when complete records cover both periods in full.
  • Scale-from-zero 503 responses (cold_start=true) cover attempts where a scale-to-zero model was either waking up (model_scaled_to_zero) or refused because no GPU capacity was free (insufficient_capacity). They are counted separately from requests and errors.
  • Usage through Open WebUI or other shared applications is recorded under that application's service key, so it does not appear here.
