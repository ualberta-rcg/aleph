Reading these numbers

  • Output speed is observed, not a benchmark: output tokens divided by the wall time your successful requests took, including queueing. Busy periods and long prompts make it lower.
  • The context window is the maximum combined prompt and completion budget configured on the model. Models with no token window (such as audio, vision detectors, or image generators) show a dash.
  • Audio endpoints record no tokens and image endpoints log request counts only; embeddings report input tokens only.
  • Thinking counts are included inside output tokens (never double-counted in total tokens). "Not reported" means the backend did not emit a separate reasoning token count.
