Reading these numbers

  • Output speed is observed, not a benchmark: output tokens divided by the time your successful requests took, including queueing and any wait for a model to wake. Busy periods and long prompts make it lower.
  • The context window is the most the model accepts for prompt and answer together. The largest prompt is the one that used the biggest share of its model's window. Models with no window, such as image generators, show a dash.
  • Audio endpoints record no tokens and image endpoints log only counts, so for those the endpoint table shows requests only. Embeddings report input tokens only.
  • Endpoints are the API paths your requests used. A model's own endpoint, such as a science model's, is named once a request to it succeeds; failed requests to unrecognised paths are counted under "other".
  • Thinking counts depend on the model: some report them and some do not. "Not reported" means the model gave no count, not that it did no thinking.
