  • Records on hand span {{longdate .Oldest}} to {{longdate .Newest}}, and this page refreshed at {{ts .RefreshedAt}}. {{if .Coverage.Partial}}{{count .Coverage.IncompleteDays "day" "days"}} in this range {{if eq .Coverage.IncompleteDays 1}}has{{else}}have{{end}} incomplete records, marked on this page.{{else}}Every day in this range has complete records.{{end}}

  • {{count . "day" "days"}} in this range {{if eq . 1}}comes{{else}}come{{end}} from saved daily totals, because the gateway's logs no longer hold {{if eq . 1}}it{{else}}them{{end}} in full. Saved days keep the same figures the pages showed at the time.
    • {{end}} {{template "gpu-note"}}
  • Thinking tokens are the part of the output a reasoning model spent thinking. Not every model reports them, so the thinking count covers only models that do; the Models page shows which.
  • Comparisons with the previous period appear only when records cover that whole period.
  • Token counts can be zero when a model does not report usage or a stream ends early. Zero does not prove no work was done.
  • Model wake-ups are attempts that found the model not running. The gateway may have started it, or refused because no capacity was free. They are counted separately and are not included in requests.
  • Usage through the browser chat or other shared applications is recorded under that application's key, so it does not appear here.
